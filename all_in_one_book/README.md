# Symfony 8.0 从零认知到精通（中文全景手册）

> 一本面向"从零到精通"的 Symfony 中文书。不是翻译，是**重写**。

---

## 本书定位

如果你在 Google 上搜 Symfony 某个报错，点进去的十篇博客里有九篇是抄官方文档、却又把最关键那一步跳过了——这本书就是为了彻底干掉那种阅读体验而写的。

- **基准版本**：Symfony **8.0**（PHP **8.4+**，与官方 `setup.rst` 声明一致）
- **底稿**：本仓库根目录的官方英文 `.rst` 文档
- **读者画像**：
  - 主目标：**完全没接触过 Symfony** 的 PHP 开发者，甚至没用过任何 PHP 框架
  - 次目标：用过 Laravel / ThinkPHP / CodeIgniter，想系统迁移到 Symfony 的人
  - 附带收益：已经用 Symfony 但"只会抄模板、不敢改配置、不会读源码"的开发者

## 本书与官方文档的差异

官方文档告诉你"**怎么写**"。这本书告诉你：

1. **为什么这么写**（心智模型先行）
2. **有几种写法、该选哪种、为什么**（选择指南）
3. **出错了怎么办**（常见报错图鉴 + 调试手册）
4. **什么时候不该这么写**（反模式）
5. **源码里到底在做什么**（深潜）
6. 以及—— **用一个贯穿全书的真实项目 `bookstore`**，让你每章都有代码增量，而不是孤立片段

## 读者承诺（四条"不"）

阅读过程中如果出现以下任何一条，视为本书 bug，请提 Issue：

1. ❌ 照着抄跑不起来（环境为 PHP 8.2+ / Symfony 8.0）
2. ❌ 读完需要再 Google 或翻源码才能落地
3. ❌ 同一概念两章之间术语不一致（见 `GLOSSARY.md`）
4. ❌ 有"待补充 / 此处略"字样

## 怎么读这本书

每一章都提供**四层入口**，按你当下的需要选即可：

| 你的状态 | 读哪一层 | 时长 |
| --- | --- | --- |
| "五分钟后开会，先知道个大概" | `01_心智模型` | 30 秒 |
| "下午要交功能，先跑通" | `02_快速上手` | 5 分钟 |
| "这周要写得像样一点" | `03_日常应用` + `04_配置项逐项讲解` | 30 分钟 |
| "我想搞懂底层 / 造轮子 / 排查诡异 bug" | `05_进阶` + `06_深潜` | 不限 |
| "报错了，救命" | `08_常见报错图鉴` + `10_调试手册` | 按需 |

## 贯穿项目：bookstore

全书共用一个虚构项目 **bookstore**（在线书店），每章都是给它加一个真实功能：

- 02 章：注册 `/books` 路由
- 03 章：写出第一个控制器
- 07 章：建立 `Book` / `Author` / `Order` 实体
- 08 章：加登录与权限（买家/管理员两套界面）
- 13 章：下单后异步发送确认邮件
- 19 章：给它写一整套功能测试
- …

每一章末尾都有 `12_bookstore_增量.md`，总索引在 `BOOKSTORE_PROJECT.md`。

## 版本说明

- 目标版本：**Symfony 8.0**
- PHP：**8.4+**（Symfony 8.0 官方最低要求，来源：仓库根目录 `setup.rst`）
- 任务书曾提到 PHP 8.2+，实际以官方 `setup.rst` 声明为准。本书所有示例在 PHP 8.4 上测试
- 第三方组件：全部按 8.0 分支的 composer 约束选版本
- 如果你用的是 Symfony 6.x / 7.x，**大部分代码仍然能跑**，但本书不对此做兼容承诺。各章遇到明确的版本差异时会单独标注。
